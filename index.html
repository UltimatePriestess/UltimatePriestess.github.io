The Steps of Making Games

As someone interested in the creation of games, I often think about the steps it takes to actually make a game like the ones you see above.There are a lot of pieces that go into game creation, for example some of the parts are:

  • Game Elements
  • Gameplay Mechanics
  • Gameplay Progression

This is just a small part of the things that goes into making a game, and there is simply too much to cover for me to explain it all. So I will simply be explaining how to start to make a game.

Starting the Journey of Game Making

The very first step into gamemaking is deciding what game you plan on creating. Through deciding what game you plan to make, you are able to understand what program you'll use, what programming language to use, the game genre to make, and so on and so fourth. Here are some links to game genres: Click Here

For example, in my game I plan to make it a memory game that would take some appects of an rpg. This game would also be done in 2D, meaning that I would be using Unity's 2D section and C# as my programming language.

Designing A Game

After figuring out the base of your game, its now time to design the game! This is where the ideas come to life, what will your main character look like, are there are any other characters? Do you have a story, or is it a game with just simple tasks? What Game mechanics do you plan to add? These are the questions you start to ask yourself, fleshing out the details of the game. You don't need to have everything ready, but getting the big idea would lead to less problems later down the line.

For me, the memory game would be set in Harlem in New York. The player would be tasked with getting items from stores, having to remember what items they were meant to get, while also being on a time limit. The player's show will start in a certain amount of time, meaning you would have to be fast getting all the items. You would be scored from F to S and getting an A or higher would mean moving to the next level.

The Final Step (Not Really)

Once the first two steps are done, you can finaly start your game, which is the hardest part. If you are beginner, this will feel daunting, because now there are so many things to do, coding, sprites, assets, levels, npcs, music, and so much more. Then you may slowly lose motivation (like me) and just start another project. This will repeat until your planning page looks like this:

Starting a game takes a lot of work, but it would be best to break it down, and starting with small goals. Like start the first level background, making tilesheets, player movement, and so on. While this is the final step for starting a game, it is far from the final step of finishing a game. You will have to discipline yourself and keep working even when you don't want to. Having the will to sit down and code for hours, and stress about a single line of code thats not working is what game making is about.
